# Changelog

## v1.0.0 — 2026-10-20

First public release.

- Blender 5.2 / EEVEE reconstruction of *I'm Upping My P(doom)*, 22 plates, 4702 frames,
  1920×1080 / 30 fps, 156.73 s.
- Python toolkit: deterministic scenes, measured typography, line art, hatching, cameras,
  compositing, baking.
- 17 scene modules, build/render/encode/QC tools, fetch and environment scripts.
- Documentation: pipeline, 22-plate table, review log, release notes, poster and stills.
- Demo film and 540p preview attached to the GitHub Release.
